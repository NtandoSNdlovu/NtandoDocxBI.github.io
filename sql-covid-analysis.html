SQL Data Exploration
& Analysis

The dataset used in this analysis focuses on global COVID-19 statistics. The objective was not prediction, but structured exploration, understanding scale, change over time, and relationships between cases, deaths, and populations.

What was the objective?

The aim was to transform raw, unstructured data into a format that decision-makers could reason about confidently.

  • Understand trends over time
  • Compare impact relative to population size
  • Identify differences in mortality rates

How was the data prepared?

Before analysis, the data was structured into relational tables and validated for consistency.

  • Separating deaths and vaccination data
  • Correct typing of numeric fields
  • Handling null values to avoid distortion

SQL exploration & analysis

Below is a representative extract of SQL used in this project. Each query builds on the previous one, from simple inspection to comparative analysis. 


-- covid-19 data exploration
-- skills used: joins, ctes, temp tables, window functions,
-- aggregate functions, views, data type conversion
---------------------------------------------------------------------

-- 1a. death percentage - world
select 
    sum(new_cases) as total_cases,
    sum(cast(new_deaths as int)) as total_deaths,
    sum(cast(new_deaths as int)) / sum(new_cases) * 100 as deathpercentage
from covid19portfolioproject.dbo.coviddeaths
where continent is not null;

-- 2a. total death count per continent
select 
    location,
    sum(cast(new_deaths as int)) as totaldeathcount
from covid19portfolioproject.dbo.coviddeaths
where continent is null
and location not in ('world', 'european union', 'international')
group by location
order by totaldeathcount desc;

-- 3a. highest infection rate per country
select 
    location,
    population,
    max(total_cases) as highestinfectioncount,
    max((total_cases / population)) * 100 as percentofpopulationinfected
from covid19portfolioproject.dbo.coviddeaths
where location not in ('world', 'european union', 'international')
group by location, population
order by percentofpopulationinfected desc;

---------------------------------------------------------------------
-- additional analysis (depth & flexibility)
---------------------------------------------------------------------

-- rolling vaccinations
select 
    dea.continent,
    dea.location,
    dea.date,
    dea.population,
    vac.new_vaccinations,
    sum(cast(vac.new_vaccinations as int))
        over (partition by dea.location order by dea.date)
        as rollingtotalvaccinations
from covid19portfolioproject.dbo.coviddeaths dea
join covid19portfolioproject.dbo.covidvaccinations vac
    on dea.location = vac.location
   and dea.date = vac.date
where dea.continent is not null;

---------------------------------------------------------------------
-- views (for reporting & dashboards)
---------------------------------------------------------------------

create view globalnumbers as
select 
    date,
    sum(new_cases) as total_cases,
    sum(cast(new_deaths as int)) as total_deaths,
    sum(cast(new_deaths as int)) / sum(new_cases) * 100 as deathpercentage
from covid19portfolioproject.dbo.coviddeaths
where continent is not null
group by date;

Why this approach works

SQL was used first to fully understand the data before any visualisation was attempted. This ensures accuracy and transparency in downstream reporting.

  • Clear, auditable logic
  • Reproducible queries
  • Reliable foundation for dashboards
